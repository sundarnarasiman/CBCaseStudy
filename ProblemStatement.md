# Problem on Credit based billing
I have been given the Credit based SAAS coding assignment for my interivew with Chargebee company. I'm sharing the problem context in the below sections

## Business Context
- Graviton is a fictional SaaS product that offers three services (S1, S2, and S3) with the following credit-based pricing model.

## Service Pricing
- Graviton offers the following service plans
- S1 requires 1 credit per usage
- S2 requires 2 credits per usage
- S3 requires 3 credits per usage

## Credit packags
- The following are the credit packages associated with various service plans
- Basic Package: 100 credits for $100.00
- Standard Package: 250 credits for $225.00
- Premium Package: 500 credits for $450.00

## Purchase
- If a customer C1 purchases the Basic Package, they have 100 credits to use across services.

## Usage Examples
- If C1 use S1 five times, it costs them 5 credits (5 * 1).
- If C1 use S2 three times, it costs them 6 credits (3 * 2).
- If C1 use S3 once, it costs them 3 credits.
- After these transactions, the customer C1 has 86 credits remaining (100 - 5 - 6 - 3).
